# 로그인 B안 적용

APK27 / 2026-10-19

- 연한 민트에서 아이보리로 이어지는 배경, 왼쪽 정렬 로고·브랜드·제목, 둥근 흰색 로그인 카드를 적용했다.
- 제목을 기존23~25px에서20~22px로 줄였다. maxLines:1, softWrap:false, FittedBox.scaleDown으로 너비가 부족할 때 한 줄 안에서 축소한다. 입력창과 버튼의 접근성 글자 크기는 제한하지 않는다.
- 아이디 저장·자동 로그인은 작은 한 줄 옵션을 유지한다. 일반 크기에서 로그인과 회원가입까지 스크롤 없이 표시하고, 키보드·큰 글자 등 공간 부족 때는 스크롤을 허용한다.
- 360×640/393×852 배치와 제목 속성, 큰 글자/키보드 버튼 접근, 기존 로그인/설정 기능 테스트 및 정적 검사를 통과했다.
- artifacts/login-design-b-preview.png는 실제 Flutter 위젯을 한글 테스트 글꼴로 렌더링한 미리보기다.
