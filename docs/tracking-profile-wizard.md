# 맞춤 기록 설정 2단계 개편

2026-10-19 / APK28

- 민트/아이보리 배경, 흰색 카드, 작은 제목·본문으로 시안을 반영했다. 관리 목표에 쓰던 임의의 주제 아이콘을 제거하고 선택 체크로 표시한다.
- 1 관리 목표 / 2 추적 항목 및 알림으로 나눈다. 하단 다음·이전·시작하기(편집은 저장하기)는 고정한다. 첫 단계 목표가 없으면 다음은 비활성화한다.
- 최초 진입과 단계 전환 시 24px 아래에서 올라오는 280ms easeOutCubic 및 페이드를 사용한다. 앱 모션 줄이기 또는 OS disableAnimations에서는 애니메이션을 없앤다.
- 선택 데이터는 단계 위 부모 State에 보관한다. 위 단계 표시, 상단 뒤로 가기, 이전 버튼, Android 시스템 뒤로 가기 모두 1단계 복귀를 지원한다.
- 추적 항목별 bool Map으로 직접 끈 항목까지 보관한다. 목표 제거/재선택 때 기본값을 덮어쓰지 않는다. 이미 선택했던 다른 목표의 항목도 유지·확인할 수 있다.
- 나만의 식습관 관리는 전체 추적 항목을 표시하고 처음에는 해제한다. 일반 목표의 새 추천 항목은 활성화하되 기존 선택이 있으면 유지한다.
- 기존 저장 프로필의 목표/활성·비활성 항목/알림을 편집에 불러온다. 저장 실패 시 선택을 유지하고 다시 저장할 수 있다. 서버 스키마와 API는 바꾸지 않았다.
- 단일 목표의 일반 화면은 짧게 구성하며, 목표 복수 선택으로 항목이 많거나 큰 글자 설정을 쓸 때는 본문만 스크롤한다.
- 검증: 작은 화면, 두 단계 선택·직접 끈 항목·알림 유지, 목표 제거/재선택, 저장 결과, 시스템 뒤로 가기, 사용자 지정 전체 항목, 모션 줄이기, 기존 편집과 저장 실패, 2배 글자, 기존 로그인→설정→홈 경로.
- artifacts/tracking-goals-preview.png 및 tracking-metrics-preview.png는 실제 Flutter 위젯 렌더링이다. 테스트의 한글 폰트는 휴대폰과 다를 수 있다.


## APK29 배치 수정

- 관리 목표 카드 안쪽에8px 여백, 항목 사이6px 간격을 추가했다. 선택 테두리를 각 항목 Material의 동일한14px 곡률로 그려 외부 카드 모서리에 잘리지 않도록 했다.
- 추적 항목 상단의 선택 목표 이름과 목표 변경 버튼을 제거했다. 제목 다음에 바로 추적 목록이 나오며 기존 단계 표시/뒤로 가기/이전 버튼으로 돌아간다.
- 첫 번째와 마지막 목표를 동시에 선택한 Flutter 렌더링으로 모서리를 확인했다. 기존 단계·선택 유지·저장과 로그인 회귀 테스트 및 정적 검사를 통과했다.
