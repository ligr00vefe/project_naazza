# 사진 분석 재시도와 직접 입력 사진 첨부

- 화면에서 분석을 시작한 뒤 20초가 지나면 지연 안내를 한 번 표시한다.
- 30초 내 결과가 없으면 로딩을 끝내고 재시도를 안내한다. 늦게 돌아온 응답은 화면에 반영하지 않고 업로드된 임시 사진을 정리한다.
- 같은 사진의 식별 실패가 두 번 연속이면 해당 사진에서 상품을 인식할 수 없다는 안내와 재촬영·직접 입력을 제공한다.
- 서버 시간 초과가 두 번 연속이면 서버 무응답으로 안내한다. 타임아웃만으로 상품을 인식할 수 없다고 단정하지 않는다.
- 새로운 사진을 선택하면 실패 횟수를 초기화한다. 3.1 모델 자동 전환은 없다.
- 직접 입력에서 사진 촬영·앨범 첨부·삭제를 지원한다. 사진 저장은 AI 분석 없이 private meals 저장소에 업로드하고 기존 식사 상세 사진 조회와 연결한다.
- 서버 로그의 storageMs/geminiMs로 다운로드·AI 응답 지연을 구분한다. 제품명과 사진 내용을 로그에 기록하지 않는다.

모델 비교: 앱은 Gemini 3.5 Flash-Lite를 사용한다. Google 공식 비교의 여러 벤치마크에서 3.1 Flash-Lite보다 개선됐지만 한국 식품 사진 인식률을 보장하는 비교는 아니다. 공식 모델 카드도 간헐적 지연·시간 초과를 명시한다.

두 모델 모두 무료 구간이 있지만 무제한은 아니다. 실제 프로젝트 청구 플랜은 API 키만으로 확정하지 않았다. 유료 표준 요금은 입력/출력 100만 토큰당 3.5 Flash-Lite $0.30/$2.50, 3.1 Flash-Lite $0.25/$1.50이다.

출처: [Google 모델 비교](https://deepmind.google/models/model-cards/gemini-3-5-flash-lite/), [공식 요금](https://ai.google.dev/gemini-api/docs/pricing), [API 한도](https://ai.google.dev/gemini-api/docs/rate-limits).

검증: Flutter 전체 테스트 40개와 정적 분석, 서버 제품명·모델 유지 테스트를 통과했다. 실제 3.5 분석은 약 28초에 ai_timeout으로 종료돼 외부 모델 지연이 여전히 있음을 확인했다. APK 빌드 13을 생성했다. 테스트 계정과 사진은 삭제했다.
