# AI 사진 분석 품질과 상품 개수

사용자 요청에 따라 3.1 자동 전환을 제거했다. 설정된 3.5 모델로 한 번만 요청하고 서버 AI 호출은 25초 제한을 둔다. 전체 앱 분석 대기는 업로드와 네트워크 처리도 포함하며 별도의 시간 제한으로 종료한다. 모델 응답 지연과 식별 실패는 서로 다른 안내로 표시한다.

한글로 보이는 제품명은 번역·해외 대체 상품명 대신 그대로 반환하도록 프롬프트를 강화했다. 상품의 표시명은 visibleProductName을 사용한다. 제품명·영양표를 읽지 못했거나 confidence가 0.85 미만이면 후보를 반환하지 않고 재촬영·직접 입력을 안내한다. AI의 확신 점수가 실제 정확성을 보장하는 것은 아니므로 영양값은 저장 전 확인한다.

포장 상품은 기본 1개로 등록하고 +/− 버튼으로 1~99개를 선택한다. 요리에는 개수 버튼을 표시하지 않는다. 한 개 전체 용량이 제공되는 바코드 제품은 그 용량을 우선 사용한다.

계산은 `1개 전체 열량 × (1개당 먹은 양 / 1개 전체 용량) × 상품 개수`다. 400kcal 상품 3개는 1200kcal이며, 1개당 1/4씩 먹은 상품 2개는 200kcal다. 저장되는 amount_g는 총 섭취량이고 unit_amount_g는 1개당 섭취량이다. 상세 기록에 개수도 표시한다.

검증: 한글 제품명·불확실한 후보 거절, 모델 변경 없는 시간 제한, 상품 수량·소분 계산 테스트를 수행했다. 실제 3.5 서버 테스트는 시간 초과 안내로 약 28초에 종료됐으며, 이 테스트에서 정상 인식 성공은 확인하지 못했다. 테스트 계정과 사진은 정리했다.
