# 제품명 조회 검증 (2026-10-15)

- AI에서 읽은 이름을 영양정보 API foodNm에 그대로 한 번만 보내던 경로를 보완했다. 실제 API는 띄어쓰기·브랜드 포함 여부가 다르면 0건을 반환했다.
- 원문 우선, NFKC/공백 정리, 브랜드 결합/분리, 일부 맛 표기를 순서대로 조회한다. 제한된 표기 규칙이며 임의의 모든 오인식·상품명을 해결하지는 않는다.
- 최대 7개 검색어, 전체 5.5초 한도다. 후보를 찾으면 종료한다. 통신/인증/한도/응답 오류는 상품 없음으로 바꾸거나 다른 검색어로 재요청하지 않는다.
- 보정 결과는 동일 상품 확정이 아닌 후보다. 제조사·맛·규격을 사용자가 확인한다. 박스 전체 용량을 낱봉지로 혼동하지 않도록 안내한다. 이전 식사 기록의 동일 이름 영양정보를 재사용하지 않는다.
- 앱은 사진에서 읽은 이름, 수정 가능한 제품명, 실제 보정 검색어를 보여준다. 페이지 추가 조회는 후보가 발견된 검색어를 유지한다.
- product-nutrition 및 nutrition-search 운영 함수에 배포했다. 실제 로그인 SDK에서 크라운 산도 밤티라미수 / 크라운산도밤티라미수 → 크라운산도 밤티라미수(161g), 해태 사브레 → 해태사브레(252g) 후보를 확인했다. 사진의 낱봉지 중량을 입증한 것은 아니다.
- 원재료는 후보의 품목보고번호로 C002를 별도 조회한다. 후보 미확정이면 원재료 연결도 할 수 없다. 확정 알레르기 정보 자동 제공은 여전히 미구현이다. 영양성분 전체 표시 개선은 별도 작업이다.
- 검증: 검색 표기 복구·오류 중단·페이지 유지 Node 테스트, 수정 검색/페이지 Flutter 테스트, 실제 배포 함수 로그인 조회. QA 계정은 로그아웃 후 삭제했다.
