# 물 마시기 기록 (2026-10-20)

- 기록하기에서 음주 기록 다음에 물 마시기를 추가했다. 홈 빠른 기록에서도 열 수 있다.
- 같은 줄의 물컵 7개를 직접 누르거나 좌우로 드래그해 0~7컵의 정수로 선택한다. 왼쪽부터 선택한 개수만큼 물이 채워진다. 별도 슬라이더나 ml 환산 입력은 없다.
- 왼쪽 경계 밖으로 밀거나 선택 지우기로 0컵을 선택할 수 있다. 오른쪽 끝 이상은 7컵으로 제한한다. 컵마다 스크린리더 선택 동작과 채워짐 상태를 제공한다.
- 세로 스크롤을 시작했다가 취소된 탭은 컵 수를 바꾸지 않는다. 입력 가능 최대 7컵은 권장량/건강 목표가 아니다.
- 날짜별 마신 **총량**이다. 같은 날짜에 다시 저장하면 기존 총량을 수정하며 누적 덧셈이나 중복 행을 만들지 않는다. 저장 전 선택만으로는 기록을 만들지 않는다. 명시적 0컵과 미기록은 구분한다.
- 날짜만 저장하며 자정에 물을 마셨다고 해석하지 않는다. UI에서 시각을 표시하지 않는다. 오늘과 과거 날짜를 선택할 수 있고 캘린더에서 선택한 날짜도 유지한다.
- 기존 기록의 날짜를 이미 다른 물 기록이 있는 날짜로 옮기면 덮어쓰지 않는다. DB 유일 제약도 중복을 막는다.
- 저장 실패 시 컵 수와 기존 기록 목록을 유지하고 다시 저장할 수 있다.
- `water_logs`: 사용자, 날짜(`drunk_on`), 컵 수(0~7), 생성/갱신 시각. `(user_id, drunk_on)` 유일 제약, 사용자 소유자 RLS, 익명 접근 불가. 계정 삭제 시 함께 제거된다.
- 캘린더 범례/물 기록 필터/날짜의 물방울 표시/상세/수정/타임라인/삭제/CSV 내보내기에 연결했다. 물 0컵도 명시적 기록이므로 표시된다.
- 물 기록은 기존 영양 충족률·공복 시간·식사 또는 음주 관찰의 노출/증상으로 사용하지 않는다. 인사이트 하단의 권장 컵 수 배너는 안내 문구 그대로 유지한다.
- 무료 외부 API/AI 호출이나 새 인증키는 필요 없다.

## 검증

- 컵 수 유효 범위, 탭/양방향 드래그, 좁은 화면과 2배 글자, 일일 총량 갱신/0컵 저장, 날짜 충돌, 실패 후 재시도, 계정 분리, 캘린더 필터, 실제 앱의 과거 날짜 경로를 테스트한다.
- 실제 서버에서 두 임시 계정으로 저장/재저장/수정/삭제, 7컵 초과 거절, 타 계정 읽기/수정/추가 차단, 익명 접근 거절을 확인한다. 검증 계정은 로그아웃 후 제거한다.
