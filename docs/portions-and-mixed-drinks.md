# 소분과 여러 주종 음주 기록

사진·바코드·영양정보 검색 결과에서 음식별로 **소분해서 먹었어요**를 체크한다. 전체 용량(g), 전체 열량(kcal), 먹은 양(g)을 확인하거나 수정하면 `전체 열량 × 먹은 양 / 전체 용량`으로 섭취 열량이 계산된다. 인식된 중량이 1회 섭취량일 수 있으므로 전체 용량은 포장 표시와 대조해 입력한다.

예: 전체 500g / 800kcal 중 125g → 200kcal. 칼로리와 다른 영양값도 먹은 양에 맞춰 비례 계산한다. 등록 시 전체 용량과 먹은 양, 소분 여부를 음식별 상세 정보에 보존한다. 직접 입력 화면에서는 기존처럼 먹은 양의 칼로리를 바로 입력한다.

음주 기록은 주종과 잔/병 선택박스로 입력한다. **주종 추가**로 다른 주종과 용량을 계속 추가하고 각각의 수량 및 소계를 저장한다. 항목 삭제 및 기존 기록 수정도 지원한다.

- 소주잔 50cc, 소주병 360cc
- 맥주컵 300/500/1000cc, 병 330/500cc, 캔 355/500cc, 페트 1000/1600cc
- 막걸리잔 200cc, 와인잔 150cc, 위스키잔 30cc, 머그잔 250/350cc
- 별도 하이볼잔 옵션 제거: 맥주컵 또는 머그잔으로 선택
- 실제 제품 용량이 다르면 직접 입력

기존 125cc 와인잔처럼 삭제된 옵션으로 저장한 기록은 그 용량을 직접 입력 값으로 보존한다. 서버에는 `alcohol_logs.details.items`로 여러 주종을 저장하며 기존 단일 주종 기록도 읽을 수 있다. 캘린더의 맥주잔 표시와 상세 화면은 같은 기록을 사용한다.

검증: 정적 분석, 전체 자동 테스트 29개, 바코드 변환 테스트, 실제 서버의 소분 칼로리·중량 및 여러 주종 저장·재조회·익명 비공개 검증을 통과했다. 테스트 계정은 로그아웃 후 삭제했다. Android 디버그 APK 빌드 9를 생성했다. 실기기 화면 확인은 별도로 필요하다.
