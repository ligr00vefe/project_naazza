# 음주 기록과 식사 표시 변경

- 주종: 소주, 맥주, 막걸리, 와인, 위스키, 하이볼, 기타.
- 소수점 잔 수를 입력하고 1잔 용량을 선택한다. 총량은 잔 수 × 용량으로 계산한다.
- 소주잔 50cc, 맥주컵 300/500/1000cc, 막걸리잔 200cc, 와인잔 125/150/175cc, 위스키잔 25/30/45cc, 하이볼잔 350/500cc, 머그잔 250/350cc를 입력 예시로 제공한다. 실제 잔은 크기가 다르므로 직접 용량을 입력할 수도 있다.
- 참고: [소주잔 50mL 제품](https://panchok.co.kr/product.php?code=2301042), [Drinkaware 계량컵의 와인·증류주 용량](https://resources.drinkaware.co.uk/products/unit-measuring-cup). 모든 예시가 동일한 업계 표준이라는 의미는 아니다.
- 달력에 음주 기록이 있는 날짜는 맥주잔 아이콘으로 표시하며 필터로 숨길 수 있다. 상세 조회와 수정도 지원한다.
- 식사는 날짜별로 아침, 점심, 저녁, 간식, 기타 순서로 표시한다. 같은 카테고리에서는 먼저 등록한 기록이 위에 온다.
- 열량은 저장된 총합을 우선 사용하고, 총합이 없는 과거 분석 기록은 음식별 열량을 섭취량에 맞춰 합산한다.
- 음식 검색은 AI가 이름에 맞는 영양정보를 추정하는 기능이다. 이름만 추가하면 영양정보를 조회하지 않으며 열량 미기록으로 표시한다.
- 내 음식 메뉴와 페이지는 사용자 요청에 따라 제거했다.
- Flutter의 제목은 공백 단위로 줄을 배치한다. 웹에서 같은 한국어 단어 끊김을 막는 속성은 `word-break: keep-all`이다.

검증: 정적 분석, 전체 자동 테스트 24개, 실제 서버 음식 검색 및 음주 저장·본인 조회·익명 비공개 검증. 임시 서버 테스트 계정은 삭제했다.
