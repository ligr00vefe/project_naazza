# 퀴노아 크래커 조회 원인 조사

2026-10-14 실제 API 응답 및 공식/판매 자료 확인.

- 영양 API는 정상 HTTP200/NODATA_ERROR(03)로 응답했다. 인증/통신/JSON 파싱 실패가 상품 없음으로 바뀐 경우가 아니다.
- 정확한 조회명: 퀴노아 크래커, 퀴노아크래커, 4번 구운 퀴노아 크래커, 4번 구워 더 바삭한 퀴노아 크래커 모두 결과 없음.
- %퀴노아% 요청도 03이었다. API가 wildcard를 지원한다는 확인이 없으므로 이를 모든 퀴노아 상품이 미수록이라는 근거로 사용하지 않는다.
- 같은 API가 뉴케어 부분명은 0건, 뉴케어 당플랜 호두맛 정확한 명칭은 1건을 반환하므로 현재 이름 검색은 정확한 등록명에 의존한다. 후보 검색이 부족한 구현 한계도 존재한다. 원본 식품코드/바코드/수입사 등의 제품 식별 정보로 추가 대조할 필요가 있다.
- C002의 퀴노아 요청은 425행을 반환했지만 조사한 첫30행에는 해당 크래커를 찾지 못했다. 전체425행을 확인한 것이 아니며 C002 미수록으로 확정하지 않는다. C002는 국내 품목제조보고 원재료 API로 수입 제품 조회를 대체하지 않는다.
- 이마트몰의 4번 구운 퀴노아 크래커300g 상품 정보는 제조국 중국, 수입자 주식회사 파머스팩토리, 수입신고 필함으로 표시한다. 사용자의 앞면 사진과 이름/문구가 유사하지만 실제 포장 중량/바코드/수입자를 확인하지 않았으므로 동일 SKU 확정이나 영양값 적용 근거로 사용하지 않는다. 340g/300g 판매 규격 차이도 존재한다.
- 영양 표준데이터는 영양성분 DB 자료를 통합한 서비스이며 국내 판매 모든 상품/포장 SKU가 실시간 등록되는 전체 유통 카탈로그라고 보장하지 않는다. 공식 설명은 기관 데이터 병합 시차도 안내한다.

결론: API 연결 장애는 확인되지 않았다. 현재 명칭 검색으로는 해당 제품을 찾지 못했으며, 실제 미수록/다른 등록명 여부는 미확정이다. 제품 뒷면의 제조사/수입사/바코드를 확인한 뒤 수입제품 데이터와 영양 DB를 추가 대조해야 정확한 원인을 확정할 수 있다. 검색 키워드/별칭/후보 검색 보완과 수입식품 공급원 조사가 필요하다. 미수록 상태에서도 사진 영양표 판독/직접 입력을 제공해야 한다.
