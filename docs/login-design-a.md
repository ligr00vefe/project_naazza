# 로그인 A안 적용

2026-10-19 / APK26

- 아이보리 배경과 코드로 그린 작은 새싹 노트 마크, 가운데 정렬된 브랜드·제목을 적용했다. 래스터 시안 자체를 배경으로 사용하지 않는다.
- 입력창 2개, 숫자 4자리 안내, 12px 아이디 저장·자동 로그인 옵션을 한 줄로 배치했다. 옵션의 터치 영역은 높이48px을 유지한다.
- 일반 화면에서는 로그인·회원가입 버튼까지 스크롤 없이 표시한다. 짧은 화면에는 로고·여백을 줄이고, 키보드·큰 글자 등으로 공간이 부족하면 스크롤을 허용한다.
- 기존 아이디 저장·자동 로그인·회원가입·비밀번호 보기 기능은 유지했다.
- 360×640 및393×852 로그인/가입 버튼 노출, 2배 글자 및 키보드 상태에서 버튼 접근, 기존 로그인/프로필/홈 흐름과 저장 옵션 테스트를 통과했다.
- artifacts/login-design-a-preview.png는 실제 Flutter 위젯으로 렌더링한 미리보기다. 테스트 환경의 Ahem 대신 Windows 한글 글꼴을 사용했으므로 휴대폰의 실제 글꼴과는 차이가 있을 수 있다.
