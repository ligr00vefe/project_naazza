# 달력 영양 표정 (2026-10-20)

- 식사가 있는 날짜에 작은 16px 표정 아이콘을 표시한다.
- 나이/성별/생애주기에 따른 기존 2025 KDRIs 기준을 그대로 사용한다.
- 하루 전체 식사 중 모든 음식에서 값이 확인된 비교 가능 영양소의 비율만 평균한다. 성분별 비율은 최대 100%다. 니아신은 mg NE가 아니므로 제외한다.
- 90% 이상: 웃음, 80~90% 미만: 미소, 70~80% 미만: 무표정, 70% 미만: 아쉬운 표정. 데이터가 없거나 개인 기준이 없으면 회색 물음표다. 식사 자체가 없으면 아이콘을 표시하지 않는다.
- 단일 성분 과다 섭취로 다른 성분의 낮은 기록률을 상쇄하지 않는다. 미확인 성분은 0으로 간주하지 않는다. 일부 성분만 확인될 수 있으므로 선택 날짜에 확인된 성분 수/비교 대상 수와 평균을 보여준다.
- 식사 기록 완료 체크를 요구하지 않는 기록 진행 상황이다. 건강 상태/영양 결핍 진단을 의미하지 않는다. 끼니 필터는 표정의 하루 전체 계산을 바꾸지 않으며 해당 끼니 기록이 없는 날의 표정은 숨긴다.
- 임신/수유 이력이 없는 상태에서 현재 임신/수유 설정을 과거 날짜에 소급 적용하지 않는다.
- 표정 아래 12px 음주/검진 아이콘, 그 아래 5px 배변(주황)/컨디션(보라) 점을 배치한다. 기존 기록별 필터와 상세 화면은 유지한다.
- DB나 API 호출을 추가하지 않는다. 기존 기록 데이터에서 즉시 계산하므로 수정/삭제 후 자동 갱신된다.
- 테스트: 경계값, 누락/실제 0, 과다량 상쇄 방지, 프로필 미설정, 과거 임신기, 작은 화면/2배 글씨, 기록 필터, 표식의 수직 위치 및 색 구분.
