# 메인 4개 화면 공통 디자인

2026-10-19 / APK30

## 공통 수정 위치

- lib/app/theme/app_design.dart: 페이지 제목18px, 구역 제목15px, 본문13px, 보조12px, 지표22px와 페이지/카드 여백·둥근 모서리 토큰. 동일 역할의 글자는 페이지에서 개별 크기를 덮어쓰지 않는다.
- lib/app/theme/app_colors.dart 및 app_theme.dart: 아이보리 배경·흰 카드·초록 강조색, 기본 글꼴 위계, 카드·칩·목록·하단 메뉴 공통 테마.
- lib/core/widgets/app_page.dart: AppPage/AppPageTitle 공통 페이지 제목·설명·너비·하단 메뉴. AppPageList 페이지 여백, AppSectionHeader 구역 제목, AppCard 카드, AppListRow/AppRecordTile 목록, AppIconBadge 아이콘 배경.
- lib/core/widgets/word_wrap_text.dart: 공백 기준 줄바꿈. 원래 문단과 접근성 문구를 유지하며 긴 단일 단어는 줄 중간에서 나누지 않고 축약한다. 짧은 제목은 한 줄로 표시한다. 기기 글자 크기 설정은 유지한다.

## 화면별 적용

- 홈: 큰 소개/캐릭터/고정 평온 상태 대신 실제 오늘 식사·배변·컨디션 기록 건수를 표시한다. 작은 빠른 기록 카드, 추적 항목, 최근 기록·진료를 사용한다. 로그아웃은 더보기 계정 항목에 배치하고 내보내기 및 맞춤 설정 접근은 유지한다.
- 캘린더: 동일 페이지/카드/구역 제목/기록 목록 사용. 달력 셀 높이를 정리하고 범례와 날짜 표식의 색을 맞춘다. 끼니 필터·검진·배변·컨디션·음주 표시 및 상세 이동은 유지한다.
- 인사이트: 공복 카드와 기간별 기록 필터를 구분한다. 긴 가로 막대 목록을 짧은 세로 막대 차트로 바꿨다. 막대를 누르면 실제 구간과 시간이 표시되며 기록 없는 구간은 회색과 미확인 문구로 구분한다. 계산식·월/연 가중 평균·구간 수는 변경하지 않았다.
- 더보기: 맞춤 설정, 기본 적용 안내, 데이터 관리, 계정의 공통 카드 그룹으로 정리한다. 안내 문구는 조작할 수 있는 옵션처럼 보이지 않게 유지한다. 모션 토글은 실제 설정에 연결한다.
