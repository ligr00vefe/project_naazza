# 아이디 저장 및 자동 로그인

2026-10-19 / APK25

- 두 옵션은 독립적이며 처음에는 모두 해제되어 있다. 아이디 저장은 성공한 로그인/회원가입의 정규화된 아이디만 기기에 저장한다. 비밀번호/PIN은 저장하지 않는다.
- 자동 로그인은 Supabase SDK 세션 저장소를 감싼 OptInSessionStorage로 제어한다. 켠 경우에만 세션을 저장·복원하며, 끄면 현재 실행 중의 메모리 세션만 유지한다. 앱이 백그라운드에 있는 것과 프로세스 재실행은 다르다.
- SDK 기본 세션 키를 유지하되 동의가 없는 이전 세션은 최초 업데이트 실행에서 제거한다. 따라서 기존 사용자는 한 번 다시 로그인하고 옵션을 선택해야 한다.
- 명시적 로그아웃은 자동 로그인 옵션 및 SDK 세션을 해제하고, 저장한 아이디는 유지한다. 아이디 저장 체크를 해제하면 기존 저장 아이디를 삭제한다.
- 서버/API/스키마 변경 없이 기기별 설정으로 동작한다. 세션의 만료·철회는 기존 Supabase 인증 규칙을 따른다.
- 테스트: 옵션 독립성, 비밀번호 미저장, 저장소 재생성 시 세션 복원/제거, 컨트롤러 로그인/로그아웃, 로그인 화면 아이디 복원/제거. 기존 로그인→프로필→홈 흐름도 검증한다.
