# 생년월일·만 나이와 영양 섭취 기준 적용

확인일: 2026-10-20

## 이번에 구현한 부분

- 회원가입 때 생년월일을 입력할 수 있다. 생년월일을 생략해도 가입할 수 있다.
- 기존 회원도 더보기 → 내 정보에서 추가·수정·삭제할 수 있다.
- 생년월일은 날짜(YYYY-MM-DD)로 계정에 보관한다. 나이 숫자를 저장하지 않고 조회 날짜의 생일 경과 여부로 만 나이를 계산한다.
- 과거 기록을 분석할 때도 `ageAt(기록 날짜)`를 사용하면 해당 날짜의 나이로 기준을 고를 수 있다.
- 미래·존재하지 않는 날짜는 거절하고, 이전 회원의 생년월일은 미입력으로 유지한다.
- 사용자 메타데이터의 생년월일은 프로필 정보다. 역할·접근 권한 판단에는 사용하지 않는다.

## 공식 기준

보건복지부·한국영양학회의 **2025 한국인 영양소 섭취기준(KDRIs)**이 있다. 41종의 에너지·영양소에 대해 연령·성별 등을 구분한다. 정오표가 반영된 최신 자료를 기준으로 버전을 고정해야 한다.

- [공식 배포·정오표 안내](https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=167)
- [보건복지부 발표 내용](https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=168)
- [2025 공식 요약본 — 서울의료원 제공 PDF](https://health.seoulmc.or.kr/uploadFiles/2025_%ED%95%9C%EA%B5%AD%EC%9D%B8%EC%98%81%EC%96%91%EC%86%8C%EC%84%AD%EC%B7%A8%EA%B8%B0%EC%A4%80_%ED%99%9C%EC%9A%A9.pdf)

| 기준 | 앱에서의 역할 |
|---|---|
| 권장섭취량(RNI) | 섭취 계획과 목표량 비교 |
| 충분섭취량(AI) | 권장섭취량을 정하지 못한 영양소의 목표 참고값 |
| 평균필요량(EAR) | 장기간의 일반적인 섭취 수준을 평가할 때 참고 |
| 상한섭취량(UL) | 초과 섭취 주의 표시. 권장섭취량 초과와 구분 |
| 만성질환위험감소섭취량(CDRR) | 나트륨 등의 별도 관리 기준. UL과 혼용하지 않음 |

생년월일만으로는 모든 기준을 확정할 수 없다. 공식 표의 남/여 기준 및 임신·수유 여부가 영향을 주므로 실제 맞춤 기준 적용 단계에서 추가 입력이 필요하다. 선택하지 않은 정보는 추정하지 않는다. 나이는 10대·20대 같은 임의 구간이 아니라 해당 영양소의 공식 연령 구간으로 연결한다. 유아·청소년에게 성인 기준을 적용하지 않는다.

## 부족·과다 표시 설계

아래는 다음 영양 관리 작업의 적용 규칙이다. 아직 앱에 자동 판정 기능을 추가한 상태는 아니다.

1. **기록 중:** 하루가 끝나기 전에는 ‘칼슘 목표의 40% 기록’처럼 진행 상태를 보여준다. 점심 전부터 섭취 부족 경고를 반복하지 않는다.
2. **목표보다 적음:** 사용자가 식사를 모두 기록했다고 확인한 날의 성분 정보가 충분할 때 ‘권장량보다 적게 기록됐어요’로 안내한다. 권장량 미만이라는 사실만으로 결핍이라고 판정하지 않는다.
3. **정보 부족:** 식사를 빠뜨렸거나 성분값이 누락되면 확인된 합계와 정보가 있는 음식 수를 보여준다. 누락을 0으로 바꾸지 않는다.
4. **상한 초과:** 확인된 섭취 합계가 해당 UL을 넘으면 ‘기록된 섭취량이 상한을 넘었어요’로 알린다. 일부 기록만으로도 이미 넘은 경우에는 초과 사실을 숨기지 않는다. 하루 초과 자체를 중독 진단으로 표현하지 않는다.
5. **상한 없음:** 임의의 과다 기준을 만들지 않는다. 상한이 없다는 사실이 무제한 섭취가 안전하다는 의미도 아니다.
6. **기준 범위 안:** ‘건강함’이나 ‘질환 없음’으로 표현하지 않고 해당 성분의 기록된 양과 기준 범위를 설명한다.

철·칼슘·비타민 C/D처럼 UL이 있는 성분은 과다 비교가 가능하다. 다만 실제 식품의 값이 확보되어야 하고, 영양제도 기록해야 총섭취량에 포함할 수 있다. 비타민 A의 레티놀, 엽산·마그네슘 등은 성분 형태·급원에 따라 UL 적용 대상이 다르므로 총 비타민 값에 일괄 적용하면 안 된다. 비타민 D는 야외 활동 시간을 합성량으로 환산해 더하지 않는다.

장기 화면은 기록이 완성된 날짜만 평균 내고 ‘7일 중 완성 기록 4일’과 같이 분모를 표시한다. 기록이 없는 날을 0으로 넣지 않는다. 성분별 정보가 있는 날짜 수도 별도로 남긴다. 신체 영양 상태나 빈혈·결핍은 이 식사 기록만으로 진단하지 않는다.

## 다음 구현 순서

1. 기존 식품 API 성분값을 섭취량에 맞춰 끝까지 보존·집계한다. 소분·개수·g/ml 단위를 검증한다.
2. 검증된 2025 KDRIs 기준표를 버전·출처·단위·성분 형태·급원 제한과 함께 앱 데이터로 구성한다.
3. 영양 기준용 성별 및 임신·수유 해당 정보를 받고, 나이와 함께 정확한 기준을 고른다.
4. 일일 기록 완료 확인과 성분별 누락 상태를 연결한 뒤 목표·상한 비교를 표시한다.
5. 철·칼슘·단백질·식이섬유·나트륨·비타민 C/D 등 확보 가능한 데이터부터 시작한다.

공식 기준표는 앱에 포함해 날짜와 프로필로 선택할 수 있으므로, 기준 비교 자체에 추가 외부 API 호출은 필요하지 않다. 식품 정보를 조회하는 API 호출량과는 별개다. 생년월일 입력 완료만으로 영양 판정까지 구현됐다고 안내하지 않는다.
